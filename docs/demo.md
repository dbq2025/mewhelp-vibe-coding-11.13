# 8 分钟演示脚本（P5）

> 目的：在 8 分钟内让人相信**这不是一个聊天玩具**——每个事实有出处、每个写操作有确认、
> 越权查不到、库挂了能说人话、指标可复现。
>
> 演示前 5 分钟只做一件事：把「已就绪」的证据准备好（见 §0），演示中不再碰终端。

## 2. 逐场景台词与预期

### ① 商品检索（0:30–1:40）

**输入**：`1000 以内的降噪耳机有哪些`

**预期输出**（措辞会变，数字不会变）：

```
1000 元以内的降噪耳机有 4 款：
- 声谷 Air Pro 主动降噪耳机，699 元，库存 120
- 极光 Buds 3 降噪耳机，899 元，库存 80
- 云雀 Quiet 2 降噪耳机，459 元，库存 150
- 云雀 Quiet Air 轻量降噪耳机，349 元，库存 180
```

**演示要点**（边等边说，约 2 秒出首字）：
1. 展开「查询过程（1 步）」→ 显示 `search_products` 与耗时。
2. 指着价格说："这 4 个数字是 SQL 查出来的，模型只负责组织语言。"
3. 顶部「已识别 价格上限」提示条 → 说明槽位是规则抽的，不是模型猜的。

**兜底**：若返回 0 款 → 改问「500 到 800 的降噪耳机」，不要现场调参。

---

### ② 多轮指代（1:40–2:30）

**输入**（同一会话）：`第二个多少钱`

**预期**：`极光 Buds 3 降噪耳机 899 元，库存 80。`（第 2 个即上一轮列表的第 2 条）

**演示要点**：
- "第二个"依赖上一轮的候选列表，属于会话状态而不是模型记忆——`get_product` 拿到的是上轮存的 `product_id`。
- 展开工具过程：这轮只有 `get_product` 一步，说明没重新搜。

**兜底**：若模型答成别的 SKU，改问 `999 的那款多少钱`，仍能证明价格来自库。

---

### ③ 订单 + 物流（2:30–3:20）

**输入**（新会话）：`帮我查下订单 20261101001 到哪了`

**预期**：待发货 / 暂无物流单号 / 极光 Buds SE ×1 / 259.00 元 / 支付时间 11-02 14:33。

**演示要点**：
- 工具过程有 2 步：`get_order` → `get_shipment`（**确定性链路**，不让模型自由编排工具）。
- "待发货 + 无物流单号"是库里的真实状态，模型没有把它说成"已发出"。

**兜底**：若答成别的状态，直接查库对照：
`docker compose exec db psql -U app -d ecom -c "select order_no,status from orders where order_no='20261101001'"`。

---

### ④ 越权拦截（3:20–4:10）

**输入**（新会话，仍是 A 登录）：`帮我查下订单 20261101023 到哪了`

**预期**：查不到，触发转人工建议；**不会**复述订单号（输出侧被替换为「另一笔订单」）。

**演示要点**：
1. 说明 `20261101023` 属于账号 B："同一句问话，换个人就问不出来。"
2. `audit_events` 里已落一条越权记录（可提前查好贴出来）：

```bash
docker compose exec db psql -U app -d ecom -c \
  "select action, created_at from audit_events order by id desc limit 3"
```

3. 讲一句设计取舍：**"越权"和"不存在"返回同一个码**（2003），防止拿订单号试存在性。

**兜底**：若模型直接说"没有这笔订单"而没提转人工，也算通过——重点是**没泄漏**。

---

### ⑤ 政策 + 引用（4:10–5:00）

**输入**（新会话）：`退货运费谁承担`

**预期**：按原因区分（七天无理由自付 / 质量问题平台承担、单笔上限 30 元），正文带 `[1][2]`；
下方引用卡片，点开 `[1] 运费规则` 能看到原文片段。

**演示要点**：
- 点开引用卡片："回答里每个结论都能点回原文，这就是 RAG 的意义。"
- 顶部「已识别 政策问题」→ 这轮走检索节点，不是商品库。

**兜底**：若引用为空，改问 `七天无理由从哪天开始算`（该文档召回稳定）。

---

### ⑥ 售后全链路（5:00–6:15）— 全场最重要

**输入 1**（新会话）：`我要退货，订单 20261101008`

**预期**：先给「待确认」卡片（订单号/商品/金额/申请事项 + 两个按钮），**此时库里还没有工单**。

**演示要点（先说这句）**："注意，现在还没有建单。写操作一律要用户确认。"

**输入 2**：点卡片上的「确认提交」

**预期**：`已经帮你提交「退货退款」申请，工单号 AS2026xxxxxxxx，当前状态：待受理。`

**输入 3**：再点一次 / 再说一次「确认提交」

**预期**：`这笔订单已经有一张「退货退款」单在处理中，单号 AS...(同一张)，不用重复提交。`

**验证（口头即可，不要敲）**：工单状态 `pending`；幂等靠"同订单同类型未完结唯一"约束 + 应用层判断。

**兜底**：若 20261101008 已有单（上次演示残留），换 `20261101009` 重走。上台前按 §4 重置。

---

### ⑦ 转人工 + 历史（6:15–6:55）

**输入**（当前会话）：`我要转人工，找客服核实一下这个订单`

**预期**：`已经帮你登记转人工，工单号 HO2026xxxxxxxx（排队中）…`

**演示要点**：
- 按 F5 刷新 → 消息全在（含工单卡片），说明落库而非内存。
- 侧栏切换另一个会话再切回来 → 不串消息。

**兜底**：若刷新后消息少一条，直接说"这是我已知的落库时序问题，会后查 traceId"。

---

### ⑧ 故障降级（6:55–7:40）— 唯一需要终端的场景

**操作**（提前开好终端，只按两条命令）：

```bash
docker compose stop db          # ① 停库
# 前端刷新 → 右上角状态点变红「服务不可用」
# 再发一条消息 → 提示「数据库暂时不可用，请稍后重试」，不是白屏也不是报错堆栈
docker compose start db          # ② 起库（约 3 秒）
# 再刷新 → 状态点变绿，继续对话正常
```

**预期证据**（有人追问时展示）：

```
GET /health      → 503 {"status":"degraded","db":"down"}
POST /auth/login → 503 {"code":5002,"message":"数据库暂时不可用，请稍后重试"}
```

**演示要点**：
- "降级不是把错误藏起来，是让调用方知道**该等**而不是**该改代码**——500 和 503 的区别就在这里。"
- 连接池在库恢复后自愈，不需要重启后端。

**兜底**：若 `start db` 后 10 秒仍未恢复，重启后端并说明连接池未自愈。

## 4. 演示前重置（让工单从"零"开始）

```bash
cd backend && uv run python - <<'EOF'
import asyncio
from sqlalchemy import text
from app.infra.db.session import SessionFactory, dispose_engine
async def main():
    async with SessionFactory() as s:
        for sql in (
            "delete from handoff_tickets",
            "delete from after_sales where source='agent'",   # 只删对话产生的，保留 seed 的 3 张
            "delete from llm_usage",
            "delete from messages",
            "delete from sessions",
        ):
            await s.execute(text(sql))
        await s.commit()
    await dispose_engine()
asyncio.run(main())
print("reset ok")
EOF
```

刷新前端即可：侧栏清空、`20261101008` 可重新走一遍售后。

## 5. 台上常见意外与应对话术

| 现象 | 立即动作 | 话术 |
|---|---|---|
| 首字超过 3 秒 | 继续讲架构，别盯屏幕 | "模型首字一般在 1.6 秒左右，这次上游有点抖" |
| 回答跑题 | 换 §2 的兜底问法 | "我换一句更明确的问法" |
| 429 请求过频 | 等 60 秒；或把 `RATE_LIMIT_PER_MINUTE` 调到 60 后重启 | "限流是按 IP 30 次/分钟，我刚才连点太快了" |
| 引用卡片空白 | 跳过，改讲工具轨迹 | "这条引用片段没返回，我讲检索链路" |
| 看板 404 | 检查 `.env` 的 `ADMIN_TOKEN` | "看板默认关闭，需要口令" |
| 完全打不开 | 用 `docs/eval.md` + 本文 §3 实测表讲 | 不硬撑，直接讲证据 |
